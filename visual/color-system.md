# Color system

## Paleta exacta

```css
--color-dark-brown: #291C0E;
--color-warm-brown: #6E473B;
--color-taupe: #A78D78;
--color-soft-beige: #BEB5A9;
--color-cream: #E1D4C2;
--color-cream-light: #F0E9DF;
--color-white: #FAF6F1;
--dark-section-base: #241A16;
--dark-section-soft: #2E211C;
--dark-section-elevated: #3A2A24;
--dark-accent: #5A4035;
--text-on-dark: #F4EEE7;
```

## Uso recomendado

- `#291C0E`: texto principal, secciones oscuras, footer y estados hover de botones.
- `#6E473B`: botones principales, acentos cálidos, links activos y microdetalles.
- `#A78D78`: acentos secundarios, barras superiores en cards y detalles editoriales.
- `#BEB5A9`: bordes suaves, separadores y apoyos visuales.
- `#E1D4C2`: fondos cálidos y texto sobre secciones oscuras.
- `#F0E9DF`: fondos claros secundarios.
- `#FAF6F1`: fondo principal, tarjetas claras y texto sobre fondos oscuros.
- `#241A16`, `#2E211C`, `#3A2A24`: superficies oscuras amplias con subtono espresso/cacao, cálidas sin virar a oliva.
- `#5A4035`: acento oscuro cálido para detalles, brillos bajos y barras sutiles.
- `#F4EEE7`: texto sobre superficies oscuras.

## Contraste

- Texto principal: `#291C0E` sobre `#FAF6F1`, `#F0E9DF` o `#E1D4C2`.
- Texto claro: `#FAF6F1` o `#E1D4C2` sobre `#291C0E`.
- Botón principal: `#6E473B` con texto `#FAF6F1`; hover en `#291C0E`.
- Bordes: usar `#BEB5A9` con opacidad para suavizar la estructura.

## Fondos claros y oscuros

Usar fondos claros para lectura biográfica, contacto y modalidad. Reservar fondos oscuros para momentos de autoridad, contraste y cierre visual, especialmente especialidades y footer. En superficies grandes, preferir la familia espresso/cacao (`#241A16`, `#2E211C`, `#3A2A24`) y dejar `#291C0E` para texto, detalles pequeños o estados puntuales.
